# NepTune

To me, software is about values

## Pillars of NepTune

1. Frictionless Ingestion
    - Laya
    - Voice Ingestion
    - File Parsing (pdf-parse, mammoth, mozilla/readability, linkedom)
    - Hybrid Organization (Hierarchy & Tags)

2. Memory Consolidation
    - Colision Detection
    - Temporal Obsolescence
    - Confidence Decay

3. UCP and Progressive Context
    - Ending Repetitive Forms
    - JIT Progressive Context
    - Context Receipts
    - MCP

4. App Memory & Review Center
    - Quarantine
    - Central Review Center (access requests, sync updates and conflicts)
    - Tombstones

5. Community Data Marketplace
    - Version Control (Path, Revision and Combine)
    - Releases
    - One click import
    - Economic Engine (B2B Ledger, Micro-loyalty)

6. Recall Surface
    - Tune App (Internal Micro-SaaS)
    - Recall Blocks (Dynamic Chat Widgets)
